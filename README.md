# 农村自建房建设规范告知书

为保障农村自建房建设安全、质量与合法合规，特制定本告知书。请建设单位（户主）、施工人员及相关参与方认真阅读并严格遵守。

## 一、建设前准备

1. **依法办理手续**：在动工前应依照当地规定办理规划、用地、报建等手续，取得相关批准文件或许可。
2. **选址安全合规**：选址应避开地质灾害易发区、洪涝区、塌陷区及高压线、燃气管道等安全保护范围。
3. **委托专业设计**：应聘请具备资质的设计人员进行结构与施工图设计，严禁私自改图或无图施工。
4. **落实建设主体责任**：户主为建设主体责任人，应对房屋质量安全负总责。

## 二、施工管理要求

1. **选择合格施工队伍**：优先选择具备相应资质或经验的施工队伍，签订施工合同，明确责任。
2. **严格按图施工**：不得擅自改变结构体系、增加层数或扩大建筑面积。
3. **规范材料使用**：使用符合国家标准的材料，禁止使用不合格或“三无”产品。
4. **施工现场安全**：做好临时用电、防火、防坠落等安全措施，配备必要的安全防护用品。

## 三、质量与安全控制

1. **基础与结构安全**：基础开挖与浇筑应满足设计要求，钢筋、混凝土等关键工序要按规范施工。
2. **抗震设防**：按所在地抗震设防要求进行结构设计与施工，确保抗震性能。
3. **隐蔽工程验收**：基础、钢筋、水电管线等隐蔽工程完成后应及时验收并留存记录。
4. **施工质量记录**：建立施工日志，记录关键工序、材料进场与检验情况。

## 四、竣工与使用

1. **竣工自检**：完工后进行自检，发现问题及时整改。
2. **依法验收**：按规定申请竣工验收或备案，未经验收不得投入使用。
3. **安全使用与维护**：使用中不得随意改动承重结构，定期检查房屋安全状况。

## 五、法律责任提示

违反规定擅自建设、违规施工、使用不合格材料等行为，将依法承担相应法律责任；造成安全事故的，依法追究相关责任。

---

**特别提示**：农村自建房建设关系到家庭财产与生命安全，请务必高度重视，严格遵守各项规范要求。

# 小说写作灵感 Issues

以下为 10 个可直接提交到仓库 Issue 区的小说写作灵感草案，每条都包含标题、核心概念与可展开方向。

## Issue 1：被遗忘的乡村时间胶囊

**类型**：现实主义 / 悬疑 / 家族叙事

**核心概念**：一名返乡青年在老宅墙体中发现一只上世纪九十年代的铁盒，里面的信件、照片和账本指向一桩被全村默契掩盖的旧事。

**可展开方向**：
- 通过时间胶囊连接三代人的选择与沉默。
- 让“修房子”的过程成为挖掘真相的隐喻。
- 结尾可以在揭露真相与守护亲情之间制造道德困境。

## Issue 2：会记仇的土地

**类型**：乡土奇幻 / 魔幻现实主义

**核心概念**：村里每块地都会记住在其上发生过的事，只有少数人能听见土地的低语；当开发商进村征地时，沉睡多年的秘密开始复苏。

**可展开方向**：
- 土地的声音可表现为梦、方言、童谣或身体疼痛。
- 主角需要判断土地讲述的是事实、怨念还是被扭曲的记忆。
- 冲突可围绕发展、祖坟、补偿款与集体记忆展开。

## Issue 3：最后一位纸老虎匠人

**类型**：民俗 / 成长 / 轻奇幻

**核心概念**：一个孩子发现村里扎纸老虎的老人能把纸兽短暂唤醒，而这种技艺即将在老人去世后失传。

**可展开方向**：
- 纸老虎可以保护村庄，也可能承载人们未说出口的恐惧。
- 主角从“觉得迷信可笑”转变为理解传统的精神价值。
- 可设置一次必须由纸老虎守夜的危机。

## Issue 4：每天凌晨 3:17 停住的钟

**类型**：心理悬疑 / 超自然

**核心概念**：老屋里的挂钟每天凌晨 3:17 停住一分钟，主角逐渐发现这一分钟里村庄会重复某个被抹去的夜晚。

**可展开方向**：
- 时间异常只在老屋范围内发生，迫使主角不断回到同一空间。
- 每次重复都揭示一个新细节，但也改变主角对亲人的记忆。
- 最终问题不是“如何逃出循环”，而是“是否愿意记住真相”。

## Issue 5：废弃水井里的来信

**类型**：悬疑 / 书信体 / 乡村传说

**核心概念**：主角清理废弃水井时捞出一叠未寄出的信，信件署名竟是尚未出生的自己。

**可展开方向**：
- 用书信体穿插叙事，制造过去、现在与未来互相写信的结构。
- 水井可以被设定为村庄“记忆的邮筒”。
- 每封信都给出一个警告，但遵守警告会带来更大的代价。

## Issue 6：拆迁前夜，全村人同时做了同一个梦

**类型**：群像 / 社会派悬疑 / 魔幻现实主义

**核心概念**：拆迁协议签署前夜，全村人都梦见一栋从未存在过的房子；第二天，现实中竟出现了它的地基。

**可展开方向**：
- 以不同村民视角呈现同一个梦的不同版本。
- 梦中房子可象征集体欲望、罪责或失落的共同体。
- 主线可追问：这栋房子是谁“欠”给村庄的？

## Issue 7：祖传施工图上的不存在房间

**类型**：建筑悬疑 / 家族秘密

**核心概念**：主角翻修祖屋时发现施工图上标注着一个现实中找不到的房间；当墙被凿开，里面却摆着与主角人生重要节点对应的物品。

**可展开方向**：
- 房间可以随主角的选择变化，像是家族命运的档案室。
- 每件物品引出一次家庭关系的重新理解。
- 最终可让主角决定是否封存、公开或改写这个空间。

## Issue 8：只在雨天营业的村口小卖部

**类型**：治愈 / 奇幻 / 单元剧

**核心概念**：村口废弃小卖部只在雨天亮灯营业，店主会卖给顾客一件“他们真正需要但不一定想要”的东西。

**可展开方向**：
- 每章围绕一位顾客和一件商品展开。
- 商品可以是旧作业本、断齿梳子、过期糖果、空白照片等。
- 主线逐渐揭示店主与村庄一场旧雨灾的关系。

## Issue 9：收音机里播放明天的新闻

**类型**：科幻悬疑 / 伦理抉择

**核心概念**：一台老式收音机每天傍晚播报第二天会发生的本地新闻，主角试图阻止坏事发生，却发现每次干预都会让新闻变得更严重。

**可展开方向**：
- 规则可以限制为只能听见本县新闻，增强地方感。
- 主角从救个人，逐步卷入村庄整体命运。
- 结尾可讨论预知是否意味着责任，以及不作为是否也是选择。

## Issue 10：没人记得的第十三户人家

**类型**：民俗恐怖 / 记忆悬疑

**核心概念**：村志记载村里曾有十三户人家，但现在所有人都坚称一直只有十二户；主角发现自己的姓氏正属于那消失的一户。

**可展开方向**：
- 通过族谱、门牌、旧照片和祭祀仪式逐步拼出空白。
- 恐怖感来自“被集体遗忘”而非直接怪物。
- 最终可以让主角在恢复存在与保持平静之间做选择。

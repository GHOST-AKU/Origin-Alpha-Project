# Origin Alpha Project 创作资料区

`creative/` 保存小说、设定、研究、视觉探索和创作图表。它是工具无关的项目目录；标准 Obsidian 打开范围仍然是整个项目根目录。

## 目录地图

```text
00_inbox/          未分类灵感
01_project/        项目级方向与跨作品探索
02_canon/          已确认的跨作品正典
03_works/          具体作品及其全部局部资料
04_research/       项目级共享研究
05_boards/         项目级白板与跨作品图表
06_attachments/    创作笔记的轻量附件
```

`boards` 就是“白板/图表”，`attachments` 就是“附件”。前面的数字只是为了让文件夹始终按预期顺序排列。

## 核心规则

- 不知道放哪里时，先放 `00_inbox/`。
- 作品专属的人物、时间线、研究和图表，全部留在对应作品目录。
- `02_canon/` 不是设定草稿箱；只有已确认的跨作品内容才能进入。
- 模板就放在它所属的内容目录里。当前没有真实作品、占位作品或作品骨架目录；第一部作品成立时再决定它的实际目录形式。
- 网站不得成为小说正文或正典设定的唯一来源。

详细使用方法见 [创作工作室使用说明](创作工作室使用说明.md)。

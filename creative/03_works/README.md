# 作品区

`03_works/` 是具体作品的创作区。当前尚未建立第一部真实作品，也没有分配 `OAP-W001`。

现有目录是已经确定的作品内容区：

```text
00_text/           正文、章节和场景
01_characters/     人物
02_world/          作品世界：地点、组织、事件和术语
03_timeline/       时间线
04_research/       作品专属研究
05_boards/         作品专属白板与图表
06_visual/         视觉作品与探索
07_audio/          音频
08_video/          影像
09_interactive/    互动媒介
10_attachments/    作品笔记的轻量附件
```

已经确定用法的内容区里就地放有对应模板。这些模板只是起始页，不是真实作品或正典内容。

第一部真实作品开始前，再根据当时已确认的作品形态，决定是否建立 `OAP-W001/` 以及它需要哪些子目录。在此之前不创建占位作品。

正式网站源文件放在根目录 `sites/`；可跨作品复用的正式原始素材放在 `assets/`。
